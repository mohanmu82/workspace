File Compare

Line up two delimited files by a key column and compare every other column. Files are read in your browser and never uploaded.
Format & Filter
The filter is tested against each raw line of both files (the header line is always kept), before anything is split into columns.
Key & Columns
Load both files to pick a key.
—
Numeric Thresholds — applies to rows in both files
When both sides of a column are numbers, a difference no bigger than the absolute threshold, or no bigger than the percentage of the File 1 value, is reported as within threshold instead of a difference. Leave a box blank to not use it. Numbers are compared as numbers, so 1.50 and 1.5 match. Text values match exactly (after the options above).
