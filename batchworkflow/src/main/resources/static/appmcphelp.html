Connect Claude Code

Point the Claude command line at this server and every enabled page action becomes a tool Claude can call. Commands below are filled in with this server's address. Manage the tools →

1. Add the server

Run this once in a terminal. batch is the name Claude Code will know the server by. Keep it short: tools appear as mcp__batch__<tool>, and the whole name has to fit in 64 characters.

2. Trust the HTTPS certificate

    
This server runs on HTTPS. If its certificate is self-signed or issued by an internal CA, Claude Code (a Node.js
        program) refuses the connection until it is told to trust it. Export the certificate and point Node at it before
        starting claude:

    
keytool -exportcert -rfc -keystore keystore.p12 -storetype PKCS12 -alias taskmanagement -file batch-cert.pem

    
# macOS / Linux / Git Bash
export NODE_EXTRA_CA_CERTS=/path/to/batch-cert.pem

# PowerShell
$env:NODE_EXTRA_CA_CERTS = "C:\path\to\batch-cert.pem"

    
Don't use NODE_TLS_REJECT_UNAUTHORIZED=0 outside a throwaway local test. It turns off
        certificate checks for everything Claude Code connects to, not just this server.


    
3. Check it is connected

    
claude mcp list
claude mcp get batch

    
Inside a Claude Code session, type /mcp to see the server's status and its tools.


    
4. Use it

    
Ask in plain language. Claude picks a tool from its description, which you can rewrite on the
        MCP Tools page. When there are many tools, Claude can call search_tools to
        find one by keyword. For example:

    
    
        
  • "Using the batch tools, look up order 12345 in UAT."
    • 
        
  • "Search the batch tools for anything about settlement, then run the status check in prod."
    • 
    

    
Every argument is optional. One Claude leaves out keeps the value saved on the use case instance, just as a
        blank field on the page does. environment picks which of the instance's environments to call.


    
5. Permissions

    
Claude Code asks before each tool call. To stop being asked for some tools, allow them in
        .claude/settings.json. Allowing mcp__batch allows every tool on the server:

    
{
  "permissions": {
    "allow": ["mcp__batch__search_tools"]
  }
}

    
Tools run real calls against real environments, production included. A tool whose use case is
        POST, PUT or DELETE changes things. Leave those on "ask", and switch off
        anything Claude shouldn't run on the MCP Tools page.


    
Troubleshooting

    

        
SymptomCheck

        
Connection failed / certificate errorStep 2. Also check that the address opens in a browser from the same machine.

        
Server connects but has no toolsOnly USECASE actions become tools. Check they are enabled on the MCP Tools page. New page actions show up within 30 seconds.

        
A tool's response says truncatedResponses are cut to 50,000 characters. Pick a narrower output on the MCP Tools page, or add a JSONata transform to the use case.

        
Calls time outThe server waits up to MCP_REQUEST_TIMEOUT (120s by default). Slow endpoints may need a timeout override on the page action.

        
Endpoint returns 404The server was started with MCP_ENABLED=false.
