Step 0 (the initial page load) always runs first automatically. selector accepts any Playwright locator (CSS, text=..., role=...). Actions needing a selector: click, dblclick, fill, type, press, check, uncheck, selectOption, hover, scrollIntoView, waitForSelector, assertVisible, assertHidden, assertText, assertExactText, assertCount, screenshot (optional). waitForTimeout uses Wait ms. press uses Key (e.g. Enter). assertText/assertExactText/assertUrl/assertTitle/assertCount/fill/type/selectOption/goto use Value.
