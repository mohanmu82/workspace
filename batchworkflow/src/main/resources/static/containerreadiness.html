Container Readiness Check

Point at a GitHub repository and check its Maven modules for what needs to change to run them as containers — missing Dockerfiles, hardcoded hosts/secrets, Kerberos/SSH usage, file-based state, and more.

Repository
Only https://github.com/<owner>/<repo> URLs are accepted. The repo is shallow-cloned to a scratch directory on the server, scanned, then deleted — nothing is kept.
