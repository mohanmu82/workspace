Gateway Router

Define runtime routes under /gateway/** that forward matching requests to backend URLs — no restart required.

Add Route
Requests to Prefix (and anything below it) are forwarded to Target URL, with the remainder of the path appended. E.g. prefix /gateway/icex/icet → target http://localhost:8090/icet forwards /gateway/icex/icet/foo to http://localhost:8090/icet/foo.
