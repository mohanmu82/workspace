Applied to the parsed response; the result comes back as transformedResponse. ${name} fills in one of this run's own values — an input, an instance input or an app variable — before the expression is evaluated, so data[orderId = "${orderId}"] keeps the row that was actually asked for. Write your own quotes: the value goes in as it stands, which is what lets a number compare as a number. Only the braced form is substituted — $sum, $map and a bare $ stay JSONata's.
