Browser Simulator

Load a URL inside a real headless Chromium/Chrome/Edge process on this server and inspect its memory footprint via the Chrome DevTools Protocol.

Load a Page

Launches a dedicated headless browser process, navigates to the URL, waits for the load event plus the settle time (lets async scripts/images finish), then captures memory metrics. Needs Chrome, Chromium, or Edge installed on this server (set CHROME_PATH if not auto-detected). On Linux, if the browser fails to launch as root (e.g. in a container), set env var CHROME_NO_SANDBOX=true — off by default since it removes a layer of isolation.
