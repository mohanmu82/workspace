Environments
A self-contained page — one row per environment with its URLs, credentials in outline, variables and comments. Passwords and keytab paths are never written into it, only whether one is set, so it is safe to send on.

A second address for this same deployment's admin endpoints. Only the use cases that set their URL Base to Monitoring are built against it — leave it empty if this environment has no separate admin address. A value starting with / resolves against this server's management port.
Layered over the app's own variables: a name set here wins over the same name on the App Definitions tab, and is itself still overridden by a use case variable or an instance input. Reference them as $region or ${region} in a URL, header or body. Values may themselves use ${DATESTAMP}, ${PREVDATESTAMP}, ${NEXTDATESTAMP}, ${DATETIME}, ${DATETIMEHR}, ${UUID}, ${MACHINE}, ${PID} or another variable.
Notes for whoever else has to use this environment. Nothing reads them at run time — they are carried into the Summary, which is where they earn their keep.
