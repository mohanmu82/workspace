MCP Tools Regression

Calls every tool on an MCP server and records the time taken, the request parameters and the result. Arguments are prefilled from each tool's input schema (default, example, first enum value) and can be edited; edits and the last run are kept in this browser so the next run compares against it. Tools run for real: "Read-only only" keeps to tools annotated readOnlyHint (tag them on the MCP Tools page); untick it to run read / write tools too.
